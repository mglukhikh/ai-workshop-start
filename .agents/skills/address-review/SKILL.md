# Code review

## Output

1. Each comment in review should be reacted exactly once.
2. Reaction includes adding a fixup commit that fixes concern from the comment, and adding a reply to the comment with the link to the added fixup commit.
3. In case a fixup commit cannot be provided, a reply should be added explaining why.

# Implement the issue

## Output

1. When the issue leaves a decision open, post the question to channel C0CM9C8D94M with SLACK_BOT_TOKEN; wait for the reply in its thread.
2. Necessary code changes in a newly-created branch.
3. Necessary tests to check if these new changes operate properly and the issue is fixed.
4. A new pull request is opened based on the branch with the changes.

## Reactions

1. After a pull request is created, check it every 5 minutes.
2. Run automatic bound to address-review skill.
